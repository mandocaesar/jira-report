# API Route Conventions

- All routes use Next.js App Router route handlers (`route.ts`)
- Auth: JWT in `auth-token` cookie, verified by `middleware.ts`
- Public routes (no auth): `/login`, `/api/auth/login`
- Database is optional — gracefully degrade if unavailable
- Use Prisma client from `lib/db.ts`

## Key Endpoints

| Method | Endpoint | Purpose |
|--------|----------|---------|
| POST | `/api/auth/login` | Password login → JWT cookie |
| GET | `/api/boards` | List Jira boards |
| GET | `/api/sprints?boardId=X` | Sprints for a board |
| GET | `/api/sprint/[id]?boardId=X` | Sprint detail + utilization |
| GET | `/api/epic-breakdown?boardId&sprintId` | Epic point breakdown |
| GET | `/api/holidays?year=X` | Indonesian holidays |
| GET/POST | `/api/leave` | Sprint leave days |
| CRUD | `/api/capacity` | Capacity adjustments |
| GET | `/api/planning/forecast?boardId&months` | Sprint forecast |

## Prisma Models

- `SprintLeave` — leave days per engineer per sprint
- `EngineerCapacity` — capacity adjustments (training, leave, part-time)
- `SprintMetrics` — historical sprint snapshots
