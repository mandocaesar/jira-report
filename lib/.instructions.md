# Library Module Conventions

## Critical: Story Points = Mandays

1 story point = 1 man-day. This is fundamental to all calculations.

## Utilization Calculation (`utilization-calculator.ts`)

- Working days = sprint days − weekends − Indonesian holidays
- Available days = working days − leave days
- Utilization % = story points / available days × 100
- Story point fields: `customfield_10036` (primary), `customfield_10052` (QA), with fallbacks

## Key Modules

- `jira-client.ts` — Jira REST API client (boards, sprints, issues, epics)
- `utilization-calculator.ts` — Sprint utilization math
- `team-roster.ts` — Team config helpers (lookup by board/accountId), reads `config/team-roster.json`
- `holiday-service.ts` — Indonesian holidays: DB `Holiday` table first, external fallback (`holiday-source.ts`: Google ICS → guangrei), cached 24h
- `db.ts` — Prisma client singleton
- `issue-helpers.ts` — Issue type categorization helpers

## Team Filtering

- `JIRA_BOARD_TEAM_MAP` env var: `boardId1:teamId1,boardId2:teamId2`
- Filter by `customfield_10001` (Team field) client-side

## Teams (from `config/team-roster.json`)

- Fund Transfer (Board 3816): 6 engineers, 1 QA
- Payment Collection (Board 3817): 10 engineers, 2 QA
- Members have: accountId, name, email, role (engineer/qa), title
