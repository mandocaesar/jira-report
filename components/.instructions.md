# Component Conventions

## Design System

- **Theme**: Dark mode with purple/pink gradient accents
- **Colors**: Gray-900 backgrounds, purple-500/pink-500 accents, glassmorphism effects
- **Cards**: `rounded-2xl`, `backdrop-blur-sm`, gradient borders
- **Animations**: Fade-in, pulse, spin loaders
- **Font**: Inter (Google Fonts)

## UI Pattern

Board selector → Sprint selector → Data display

## Key Components

- `Sidebar.tsx` — Collapsible nav (sections: Dashboard, Planning, Settings, Analytics)
- `BoardSelector.tsx` — Jira board dropdown
- `SprintSelector.tsx` — Sprint dropdown (depends on selected board)
- `SprintSummary.tsx` — Working days, points, QA/Eng breakdown cards
- `UserUtilizationCard.tsx` — Individual engineer utilization
- `EpicBreakdown.tsx` — Epic-level point distribution
- `CapacityAdjustmentModal.tsx` — Add/edit capacity adjustments
