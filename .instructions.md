# Jira Sprint Report

Internal dashboard for Jira sprint utilization & capacity planning (Bank Sinarmas).

## Critical Rules

- **Story points = mandays** (1 story point = 1 man-day)
- Jira story point fields: `customfield_10036` (primary), `customfield_10052` (QA)
- Jira team field: `customfield_10001`
- Board→Team map: `JIRA_BOARD_TEAM_MAP` env var (`boardId:teamId,...`)

## Tech Stack

Next.js 16 (App Router), TypeScript, Tailwind CSS v4, PostgreSQL 16, Prisma 5, JWT auth (jose), Vercel deployment.

## Issue Categorization

- **Product**: Story, Task, Sub-task
- **Technical Initiatives**: Technical Initiative, Chore
- **Incident**: Incident, Bug, Defect

## Maintenance

- When creating a new page, component, lib module, or API route, update `docs/project-map.md` with the new entry.

## Dev Commands

- `docker compose up -d` — start local DB
- `pnpm run dev` — start dev server
- `npx prisma migrate dev` — run migrations
- `npx prisma generate` — generate Prisma client
